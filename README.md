# vending_machine
 
• Designed and verified a predominantly Moore FSM-based vending machine 
in Verilog HDL supporting four products with coin insertion, product 
selection, cancel operation, and automatic change return.  
• Implemented a 19-state FSM for transaction control and state-based product 
dispensing, with input-driven refund logic. 
•  Developed a testbench to verify functional correctness through simulation 
and waveform analysis across normal, cancellation, and overpayment 
scenarios, ensuring reliable operation and accurate state-based behaviour.
